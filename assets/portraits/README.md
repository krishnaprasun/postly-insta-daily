# Portraits of public figures

Drop image files here, named after the person:

    rajiv-gandhi.jpg
    b-r-ambedkar.jpg
    lal-bahadur-shastri.png

When a file matching the person exists, the system uses **the photograph** for
the designs that show a face, instead of generating a likeness — and the
"check the portrait" warning switches off, because there is nothing to verify.
The one framing that shows no face (their emblems as a still life) still
generates, by design.

**Best results:** a PNG with a transparent background, or a photo on a plain
white background — those get cut out and floated on the canvas. A photograph with
a real background still works; it is framed as a medallion or arch instead.

Portrait-orientation, head and shoulders, at least 800px tall.

## Licensing

These go out on a public brand account. **Use only images you have the right to
publish.** Government-released and public-domain portraits are usually safe; a
photograph found through an image search usually is not.
